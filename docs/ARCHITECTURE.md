# 構成

- manifest.json: zip,cbzのthumbnail/viewerと公式ffmpeg依存を登録。他の拡張子に作用しない。
- lib/archive.cjs: yauzlの中央ディレクトリ読み込み、名前のデコードと自然順、CRC/サイズ/画像寸法チェック。画像は1ページずつメモリへ読み、動画だけ指定先へストリーム保存する。
- lib/video.cjs: 公式FFmpegパス確認、動画の一時領域・排他・容量管理、先頭署名確認、静止画生成、明示的な外部起動と保持を担当する。
- lib/video-lock.cjs: Windowsでは正規化したcache root由来の名前付きパイプを取得してから互換用ファイルガードを扱う。旧PIDが終了済み、または新方式の残存ガードだけを復旧する。非Windowsはファイルガードのみで自動復旧しない。
- lib/video-name.cjs: 元の末尾ファイル名を保ち、Windows禁止文字・予約名・過長名だけを安全化する。拡張子は動画の許可リストに限定する。
- lib/retry.cjs: 読み出し・生成のエラーを初回＋最大3回まで再試行する。待機は中止可能で、外部起動には適用しない。
- viewer.js: Eagleのpathクエリを受け、ブラウザ内Blob URLで画像や動画の静止画を表示。処理を直列化して連打の古い要求を破棄し、ページ切替・終了時にURLと未起動の一時動画を解放する。
- 初期フォーカス: 文書開始時の一度だけwindow/stageに要求する。非表示・prerender・選択済みコントロールは尊重し、読み込み完了後やページ変更時に取り直さない。Eagleが要求を受けるかはホスト側の挙動に依存する。
- lib/immersive.cjs: ホストの全画面状態を読み、CSSクラスだけを切り替える。F5やウィンドウ操作は行わず、API不明時は通常表示を維持。resize等で再判定し、古い非同期応答を無視する。
- thumbnail.cjs: 先頭画像、なければ先頭動画の静止画をDOM canvasで最大400pxのPNGへ変換しdestへ保存。依存がなければ展開前に汎用アイコンへ切り替える。
- tests: 実データを使わない合成ZIP、ブラウザを起動しないDOM模擬試験、明示された信頼済みFFmpegを使う任意の合成動画試験。

同梱JS依存はyauzl、image-size、iconv-lite。各ライセンスは同梱node_modules内に保持。FFmpegバイナリは同梱せず、Eagle公式依存から渡されたローカルの絶対パスのみ使用する。共通の展開処理を二重実装せず、ZIP64などの構造解析はyauzlへ委譲する。CRC32は展開後の整合性とUnicode名のextra field検証に使う。

全画像のメモリ読み込みやディスクキャッシュを行わず、一覧用の名前と読み出しに必要な数値フィールド、1ページだけを保持する。ZIP中央ディレクトリの元Buffer・コメント・extraは保持せず、走査するメタデータ合計にも8 MiBの上限を設ける。画像デコーダー自体はEagleの実装なので、画素数・圧縮サイズの上限はあるがプロセスの厳密な最大メモリを保証しない。

動画は専用tempフォルダーの容量確認とストリーム書き込みを排他し、生成した一意のサブフォルダーへ、安全化した元の末尾ファイル名で保存する。元のディレクトリーは使わない。書き込み終了後に自分のガードを照合・削除し、最後に自分のIPCを解放する。旧版もwxガードを取るため、新旧混在でも同時展開しない。CRCと先頭署名の確認後にhandleを返し、同じファイルでFFprobe/FFmpegを非同期に開始する。posterReadyを待たずに外部起動でき、生成失敗は最大3回再試行してからposterErrorへ保存する。shellなし・非表示・制限時間付きで、入力プロトコルとコンテナを限定し、静止画出力も800px・2 MiBまでとする。OSレベルのメディアデコーダー隔離ではない。

外部起動は任意のeagle.shell.openPathをボタン操作時にだけ呼び、自動再試行しない。起動前にopened.jsonを書き、そのファイルはビューア終了時も保持する。保持済み動画を自動掃除しないため、上限到達時や異常終了後はREADMEに従う手動整理が必要。未起動動画の削除はハンドルに保存した正確な所有パスに限定し、再帰削除やリンク追跡をしない。

ページ表示の自動再試行はZIPの開き直しを含む。同じ名前/選択を優先し、手動操作のticketとAbortControllerが古い結果と待機を止める。動画ポスターは別の上限付き処理で同じ一時動画を再利用し、ポスター失敗を外側へ再送して回数を掛け合わせない。

容量走査中に別画面が古い一時動画を片付けることがある。列挙済みvideo-*フォルダーのlstat/readdirと内部ファイルのlstatでENOENTになった項目だけは、消滅済みとして扱う。その他のエラーやルート自体の消失、未知名、リンクは許容しない。
