# ZIP Image Viewer for Eagle

ZIP / CBZを1つの[Eagle](https://eagle.cool/)項目として保存したまま、画像と動画の静止画を閲覧するFormat Extensionです。動画の再生はOS既定の外部アプリへ渡します。Eagle公式の製品ではありません。

## 機能

- ファイル名の自然順（1、2、10）、ページ一覧、前後移動。
- 画像の画面フィット・幅フィット・原寸表示。
- 先頭画像の表紙生成。動画のみのZIPは先頭動画の静止画を使用。
- 動画の1秒位置の静止画。短い動画で1秒にフレームがない場合は先頭へ戻ります。
- 展開・CRC検査後は静止画の完成を待たず「外部プレイヤーで開く」を使用できます。
- 全画面を検知すると上下バーを格納し、上下端ホバーやTabで表示。
- ホストの初期化完了後に一度だけビューアーへフォーカスを要求。左右キーで内部ページを送れます。
- 読み込み・静止画生成のエラーは初回＋最大3回で終了。外部アプリ起動は自動再試行しません。
- Shift_JIS / UTF-8 / CP437のファイル名を扱えます。

## 開発版の導入

Node.js 18以上とEagleが必要です。

```sh
npm ci --ignore-scripts
npm test
npm run check
npm run package
```

Eagleのプラグイン管理で「ローカルプロジェクトをインポート」を選び、生成されたdist/eagle-zip-image-viewer-0.5.1フォルダーを指定します。最初は小さなテスト用ZIPで確認してください。他のZIP/CBZハンドラとは競合する可能性があります。導入しただけで既存項目の表紙が再生成されるとは限りません。

同時に作る.zipは開発用アーカイブです。正式な.eaglepluginではありません。正式形式は[Eagleのパッケージ化機能](https://developer.eagle.cool/plugin-api/ja-jp/distribution/package)で作成します。同じ版の成果物は上書きしません。

動画の静止画には[Eagle公式FFmpeg依存](https://developer.eagle.cool/plugin-api/extra-module/ffmpeg)が必要です。依存が利用できなければ静止画を省略し、動画のみの表紙は汎用アイコンになります。FFmpegの自動ダウンロード、PATH検索、固定の個人用パスは使いません。

## 操作

- ← / →、PageUp / PageDown、Space / Shift+Space: 前後のページ。
- Home / End: 最初 / 最後。F: 表示サイズの切り替え。
- ↻: ZIPの再読み込み。
- ボタンや選択欄へ移動した後は、そのコントロールのキー操作を優先します。ホストが初期フォーカスを制限する場合は画像領域をクリックしてください。
- 画像領域はクリックや初期フォーカスでは枠線を表示しません。Tabで移動した場合はフォーカス位置を表示します。
- 全画面時は上下端10pxへのマウス移動かTabフォーカスでバーを表示。F5やEscapeはEagle側の操作を変えません。

## 対応形式と制限

画像: JPEG / PNG / GIF / BMP / WebP。動画: MP4 / M4V / MOV / AVI / MKV / WebM。動画の静止画と外部再生の可否はコーデックと環境によります。

ZIPはStore/Deflate、最大4 GiB・20,000項目・申告展開サイズ合計8 GiB。中央メタデータ8 MiB、名前4,096まで。画像は圧縮/展開サイズ各64 MiB・6,000万画素・各辺32,768まで。動画は圧縮/展開サイズ各2 GiBまで。暗号化・分割ZIP・リンク・不正パス・CRC不一致はエラーです。入れ子ZIP、SVG、PSD、PDF、隠しファイルは表示しません。

画像はメモリへ1枚ずつ読みます。動画だけはOSのtemp配下のeagle-zip-image-viewer-videosへストリーム展開します。一時領域は8 GiB・128本まで。各動画は一意のフォルダーに元の末尾ファイル名で保存し、禁止文字・予約名・過長名だけを安全化します。原本ZIPやEagleライブラリへ画像/動画をばらして追加することはありません。

外部へ渡していない一時動画はページ移動/終了時に片付けます。外部へ渡した動画はプレイヤー終了を確実に検知できないため、自動削除しません。上限到達時や強制終了後の整理は、Eagleと外部プレイヤーを閉じてから専用フォルダーだけを対象にしてください。Temp全体を削除しないでください。

WindowsではOSの名前付きパイプと互換用ファイルガードで展開を直列化し、所有者が終了したと確認できる旧ロックを復旧します。生存中・不明・権限不明のロックは奪いません。非Windowsはファイルガードのみで、自動復旧はしません。展開120秒、FFprobe/FFmpeg各20秒などの上限はありますが、メディアデコーダーの厳密なOS隔離を保証するものではありません。信頼できる更新済み外部プレイヤーを使用してください。

## 互換性と検証範囲

開発初期のプラグインです。合成ZIPの自動試験とWindowsでの実FFmpegによるMP4/AVI/短いMP4を検証しています。画像閲覧と動画静止画の一部はEagle 4.0.0で確認されていますが、すべての形式・UI動作を実機確認したものではありません。0.5.0では初期フォーカスが効かない実機報告があり、0.5.1で要求タイミングを見直しています。この修正と非Windowsでの動作は実機未確認です。

初期フォーカスは利用可能なら最初のonPluginRun通知後、なければwindow load後の描画時に一度だけ要求します。開始から1.5秒を過ぎるか、待機中にキー・クリック・フォーカス移動・非表示を検知した場合は取りやめます。読み込みの完了や再試行を理由にフォーカスを取り直すことはありません。ホストの外側の操作をすべて検知できる保証はありません。

Format ExtensionのビューアーでのPlugin APIは公式保証されていません。全画面検知、FFmpegパス取得、外部起動はEagleのバージョンに依存します。API不明時は全画面バーを通常表示のままにし、外部起動できない場合はエラーを表示します。

任意の実FFmpeg試験は、既存の信頼できる依存フォルダーをEAGLE_TEST_FFMPEG_DIRへ設定してnpm run test:videoで実行します。この変数は試験専用で、製品コードは読みません。外部アプリやEagle UIは操作しません。GitHub ActionsのCIは設定していません。

構成は[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)を参照してください。
